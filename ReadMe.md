\# Scalable Notification System



\## Project Overview



This project is to generate and design the architecture and core implementation of a highly-scalable notification system.  This system will be designed to reliably deliver billions of messages across multiple channels with features such as scheduling and idempotency.  The channels of focus will be Email, SMS, and Push Notifications.



\### Project Focus



As a design exercise this project will emphasize decoupling, fault tolerance, high volume, low-latency, and bounce back handlings.
